# Gym app

Persoonlijke app voor iPhone: trainingslogboek, progressie, trainingsstreak en contentplanner.

- Open op je iPhone in Safari: https://oeloexx.github.io/gym-app/
- Kies Deel → Zet op beginscherm.
- Je trainingsdata staat alleen op je telefoon (maak af en toe een backup via het tandwieltje).
- Nieuwe versies: in de app op **Updaten** tikken.

## Bronnen
Oefenfoto's: [free-exercise-db](https://github.com/yuhonas/free-exercise-db) (public domain).
Voedingswaarden zijn richtwaarden per 100 g.
